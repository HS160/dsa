# Data Structures and Algorithms (DSA) in Python

## Overview
This repository contains my journey of learning Data Structures and Algorithms using Python. It serves as both a learning resource and a reference for fundamental DSA concepts and their implementations.

## Repository Structure
```
├── Arrays/
├── LinkedLists/
├── Stacks/
├── Queues/
├── Trees/
├── Graphs/
├── Sorting/
├── Searching/
└── Advanced_Algorithms/
```

## Topics Covered
- Basic Data Structures
  - Arrays and Lists
  - Linked Lists (Singly and Doubly)
  - Stacks and Queues
  - Trees and Graphs
  
- Algorithms
  - Searching Algorithms
  - Sorting Algorithms
  - Dynamic Programming
  - Recursion
  - Graph Algorithms

## Code Structure
Each implementation includes:
- Core algorithm/data structure implementation
- Time and space complexity analysis
- Example usage
- Problem-solving approaches
- Test cases

## Getting Started
1. Clone the repository:
```bash
git clone https://github.com/HS160/DSA-Python.git
```

2. Navigate to the specific topic:
```bash
cd DSA-Python/<topic_name>
```

3. Run the Python files:
```bash
python <filename>.py
```

## Prerequisites
- Python 3.x
- Basic understanding of Python programming
